### 📊 Task 7: Sales Summary with Python and SQLite

This task demonstrates how to use **Python** with **SQLite** to perform basic data analysis and visualization on sales data. A small SQLite database (`sales_data.db`) is created containing product sales records. The script uses **SQL queries inside Python** to calculate:

- ✅ Total quantity sold per product  
- ✅ Total revenue per product  

The results are loaded into a **pandas DataFrame**, printed to the console, and visualized using a **matplotlib bar chart**. The chart is also saved as an image file (`sales_chart.png`).

####  Tools & Libraries Used:
- `sqlite3` for database connection and SQL execution  
- `pandas` for data manipulation  
- `matplotlib` for visualization

####  Learning Outcomes:
- Writing basic SQL queries with aggregation (`SUM`, `GROUP BY`)
- Importing SQL results into Python using pandas
- Creating simple data visualizations
